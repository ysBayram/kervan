# Security Policy

We take the security of Kervan seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

## Supported Versions

Currently, the project is in early development. Security support is provided on a best-effort basis for the latest main branch or pre-releases:

| Version | Supported |
| ------- | --------- |
| < v0.1.0-alpha (main) | Best-effort / Active |
| Older | No |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

Instead, please report security vulnerabilities by either:
1. Opening a private draft Security Advisory on GitHub (if enabled for the repository).
2. Contacting the project maintainer via the email/contact details listed on the repository owner's profile (`ysBayram`).

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Detailed steps to reproduce the issue (including proof-of-concept code or configuration where possible).
- Any details regarding your environment.

## Our Process

- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Investigation:** We will investigate the issue and coordinate a fix.
- **Disclosure:** Once a fix is ready and a release is prepared, we will publish a security advisory and credit you for the discovery (unless you prefer to remain anonymous).
